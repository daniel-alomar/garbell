# Documentació en català i anglès

[Català](idiomes.md) · [English](../en/languages.md)

## Estructura actual

`README.md` és la portada anglesa i `README.ca.md` conserva la catalana.
`docs/ca/` i `docs/en/` contenen les guies equivalents. La presentació dels
exemples i el recorregut pràctic també estan disponibles en les dues llengües.
Cada guia traduïda enllaça amb la seva equivalent; la guia anglesa de visualització
es troba fora de la volta de demostració per no barrejar-ne el contingut.

## Manteniment

Actualitza les dues versions quan canviï una funció. Si queda una traducció
pendent, indica-ho a la pàgina afectada. La revisió de correspondència d’aquesta
edició és del 2026-10-04; no s’atribueix revisió humana professional.

## Instruccions i exemples

La skill, les seves referències, els rols i el context conserven una sola
implementació operativa en català. Les guies angleses expliquen l’ús; els
enllaços cap a instruccions operatives indiquen que són en català. No es creen
skills duplicades ni es tradueixen claus de configuració o identificadors.

Garbell utilitza prosa en català per defecte si l’usuari no demana una altra llengua. Per crear una volta anglesa, demana explícitament l’anglès.

Els originals, les notes i els localitzadors dels exemples continuen en català,
amb guies angleses per navegar-los i provar les peticions. Les cites i els títols
bibliogràfics conserven l’original. No s’ha traduït cap volta personal.
