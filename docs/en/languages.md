# Documentation in Catalan and English

[English](languages.md) · [Català](../ca/idiomes.md)

## Current layout

`README.md` is the English landing page; `README.ca.md` preserves the Catalan
version. `docs/ca/` and `docs/en/` hold equivalent guides. The example overview
and practical walkthrough are also available in both languages. Each translated
guide links to its counterpart; the English visualization guide lives outside
the demo vault to avoid mixing its content.

## Maintenance

Update both versions when functionality changes. If a translation is pending,
say so on the affected page. Content correspondence was reviewed for this
edition on 2026-10-04; no professional human language review is claimed.

## Instructions and examples

The skill, its references, roles and product context retain one operational
implementation in Catalan. English guides explain usage; links to operational
instructions identify their language. There are no duplicate skills, and
configuration keys and identifiers are not translated.

Garbell defaults to Catalan prose unless the user requests another language. Ask for English explicitly when creating an English vault.

Example originals, notes and locators remain in Catalan, with English guides
for navigating them and trying requests. Quotations and bibliographic titles
retain their original language. No personal vault has been translated.
