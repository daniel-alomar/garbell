# Rols opcionals de treball

Aquests fitxers són guies Markdown. No instal·len ni arrenquen agents.
El flux habitual de `$garbell` es pot completar en una sola sessió.

- [Coordinador](coordinator.md): prepara i integra el lot, com a únic escriptor.
- [Revisor](evidence-reviewer.md): comprova les propostes amb les fonts i retorna incidències,
  sense modificar la volta. Utilitzar aquest rol addicional és opcional.

No confonguis aquesta carpeta amb `skills/garbell/agents/`, que conté les
metadades de presentació de la skill. El repartiment entre agents separats
requereix una petició de l'usuari i un entorn que ho pugui executar.
[Explicació del procés](../docs/ca/funcionament.md).
