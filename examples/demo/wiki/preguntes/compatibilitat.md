# Quan serien incompatibles dos resultats?

**Pregunta de recerca proposada, encara no resolta.**

Quines hipòtesis addicionals permetrien passar d'una inferència gravitacional
a una predicció contrastable pel detector de l'altre estudi?

La [[wiki/sintesis/comparacio|comparació]] suggereix delimitar un model comú
abans d'afirmar incompatibilitat. Aquesta és una proposta de l'agent, no una
conclusió dels autors. Cal llegir els textos complets i incorporar fonts
sobre el model escollit; els abstracts actuals no responen la pregunta.

Pròxim pas suggerit: fer una taula d'hipòtesis, observables i incerteses amb
localitzadors verificats. No generar-ne valors a partir de coneixement no
aportat. Vegeu [[wiki/pendents|lectures pendents]].
