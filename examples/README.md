# Exemple fictici de Garbell

Aquesta carpeta sencera és opcional i eliminable. No és una plantilla que
s’apliqui automàticament a les voltes. No forma part de `skills/garbell/`.

- `demo/raw/`: dues fonts sintètiques amb seccions numerades.
- `demo/wiki/fonts/`: fitxes de les fonts.
- `demo/wiki/sintesis/comparacio.md`: síntesi connectada i atribuïda.
- `demo/wiki/index.md`: punt d’entrada d’Obsidian.

Obre `demo/` com a volta per veure el resultat, o copia només `demo/raw/` a
una carpeta temporal i demana a $garbell una demostració. No ho copiïs a la
teva biblioteca real. La sortida esperada il·lustra atribució i desacord;
la redacció i els enllaços no han de reproduir-se literalment.

Pots eliminar `examples/` o generar el paquet sense exemples amb
`python3 scripts/distribute.py --without-examples`.
