# Try Garbell as a research aid

[English](WALKTHROUGH.en.md) · [Català](PASSEIG.md)

This prepared example lets you explore the workflow; it does not prove that
any agent performs a correct scientific review. It uses real abstracts and
original summaries. Use a temporary copy to try additions.

## 1. Retrieve information with provenance

Scenario: you have started collecting dark matter readings and want to prepare
for a meeting. Open `demo/` in Obsidian. Ask:

> Which lines of investigation are represented in the corpus? Compare the
> documents' questions and link each claim to the passage consulted. State
> the scope of reading.

The expected result separates cluster observations, experimental searches and
cosmological inference. The [three-way matrix](demo/wiki/sintesis/tres-vies.md)
shows one possible organization. The agent should not present three numbers as
if they measured the same thing or combine evidence without checking dependencies.

## 2. Prepare a synthesis and identify missing work

> Prepare a short discussion outline covering what we can say, what is
> interpretation, and what we need to read before defending a conclusion.

A useful answer points to sources, separates organizational proposals from
authors' conclusions and ends with specific reading tasks. The
[reading plan](demo/wiki/preguntes/pla-lectura.md) is one possible output.
It does not invent a thesis question or assume full papers were read.

Also try: “Does the LZ result automatically contradict the other two?” The
comparison should explain that questions and hypotheses differ and an explicit
model would be needed to establish incompatibility. Abstracts do not resolve
this broad question. The answer must be traceable to source notes, rather than
relying solely on a journal's reputation.

## 3. Navigate what you have

> Which works are available by journal? What format is the LZ document?
> Which versions and sections were consulted?

The [journal catalogue](demo/wiki/revistes.md) retrieves works by journal;
[document types](demo/wiki/tipus-documents.md) distinguish type and format.
The LZ note preserves evidence for its Letter format. Reading metadata and
an abstract does not become full reading of a published version.

## 4. Watch the knowledge base expand

To reproduce an addition, first copy only the Clowe and LZ summaries to a
temporary input folder and create a new vault with Garbell. Then add
`planck-2020.md` to that input and ask:

> Incorporate this source. Expand the comparison where it adds a useful
> perspective, update the catalogues and record what could not be verified.

The third source should add a line of investigation, a source note and traceable
dependencies. The earlier two-study comparison can remain valid within its scope.
The metadata note about a correction should create pending reading, not a claim
that the agent has already evaluated its effects.

## 5. Move to full documents

When you have the full papers, provide them to the temporary copy and request
detailed reading with pages and figures. The agent must distinguish this new
scope from the summaries, reuse the work's identity and revisit affected
syntheses. This step requires the documents; it is not presented as completed
in the included demonstration.

The practical benefit is moving from a question to evidence and reading gaps,
and maintaining those relationships as the corpus grows. The graph helps
exploration; claims and locators make the result reviewable.
